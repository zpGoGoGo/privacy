隐私政策

产品名称：JSON 工具（JSON Tool）

Product: JSON Tool · Effective: 2026-07-20

核心承诺：本软件不收集、不存储、不传输任何个人信息。

Core pledge: This software does not collect, store, or transmit any personal information.

1. 信息收集

本软件不收集用户的任何个人信息，包括但不限于：姓名、邮箱、电话、设备标识、地理位置、使用行为、输入内容等。

This software does not collect any personal information, including but not limited to: name, email, phone, device identifier, location, usage behavior, or input content.

2. 联网行为

本软件主体不联网。除微软商店自带的自动更新机制外，软件不发起任何 HTTP 请求、不嵌入任何联网 SDK、不上传任何用户数据。

This software is primarily offline. Aside from the Microsoft Store's built-in auto-update mechanism, the software does not initiate any HTTP requests, embed any online SDK, or upload any user data.

3. 广告与第三方跳转

本软件底部含 CPS 联盟推广横幅（淘宝联盟 / 京东联盟）。该横幅的行为边界如下：

  • 软件本身不联网加载广告素材，横幅文案与链接已内嵌在软件安装包内
  • 仅当用户主动点击横幅时，软件会调用系统默认浏览器打开第三方电商页面
  • 跳转后的浏览与成交数据由第三方电商平台收集，本软件不读取、不上传任何此类数据
  • 用户可随时点击横幅右侧的 × 按钮关闭广告

The software contains a CPS affiliate banner (Taobao / JD) at the bottom. The banner's boundaries:

  • The software itself does not load ad assets online; text and links are bundled in the installer
  • Only when the user actively clicks the banner does the software invoke the system default browser to open a third-party e-commerce page
  • Browsing and transaction data after redirection are collected by the third-party e-commerce platform; this software does not read or upload any such data
  • The user can close the banner at any time via the × button on the right

4. 本地数据

本软件不写入任何本地文件、不读取用户本地其他文件的内容。软件运行所产生的临时数据仅存在于内存中，关闭软件即释放。

This software does not write any local files or read the contents of other user local files. Temporary data generated during runtime exists only in memory and is released when the software is closed.

5. 儿童信息

本软件面向开发者与测试人员，不面向儿童，亦不收集任何儿童信息。

This software is intended for developers and testers, is not directed at children, and does not collect any children's information.

6. 政策修订

本隐私政策可能因软件功能变化或法律法规要求而更新。更新后的政策将以新版本号和生效日期在本页面公布，不另行单独通知。

This privacy policy may be updated due to software feature changes or legal requirements. Updates will be published on this page with a new version number and effective date, without separate notification.
